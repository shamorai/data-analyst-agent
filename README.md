# Data Analyst Agent

An autonomous AI agent for data analysis, automated querying, and data visualization.

## Features
- Automated SQL & CSV data querying
- Interactive UI using Streamlit
- Powered by LLMs and LangChain / LangGraph

## Quickstart

1. Clone the repository:
   git clone https://github.com/devupadhyay01/data-analyst-agent.git
   cd data-analyst-agent

2. Install dependencies:
   pip install -r requirements.txt

3. Set environment variables:
   Copy .env.example to .env and add your API keys.

4. Run the app:
   streamlit run app.py
